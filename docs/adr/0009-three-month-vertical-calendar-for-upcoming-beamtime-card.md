# Three-Month Vertical Calendar View for Upcoming Beamtime Card

The `upcoming_beamtime` dashboard card previously rendered beamtime allocations as an unanchored linear list of upcoming shifts, making it difficult for researchers to visualize temporal proximity, shift spans, and logistical gaps relative to their dewar shipment schedules and operational planning. Rather than adopting an external heavy JavaScript calendar framework or paginated full-width schedule grid that would disrupt the 3-column dashboard layout, we decided to refactor `UpcomingBeamtimeCard` into a compact, vertically stacked three-month calendar view (displaying the current month and the two subsequent months). The view is generated server-side in `mxlive.dashboard.services` using Python's standard `calendar.Calendar` module and rendered via Django templates into compact Monday–Sunday mini-grids sized specifically for the card's left sidebar column (`col-12 col-md-3`). Scheduled beamtimes are annotated with their operational Access Mode colors (`AccessType.color`), multi-day and multi-shift allocations are highlighted across their scheduled date ranges, and interactive popovers provide quick access to beamline acronyms, shift summaries, active session details, and the upstream `beamtime-info` modal. This architecture preserves server-side template modularity, avoids client-side calendar dependencies, optimizes responsive sidebar space, and provides researchers with immediate 90-day operational clarity.
