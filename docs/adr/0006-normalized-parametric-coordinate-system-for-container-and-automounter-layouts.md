# Normalized Parametric Coordinate System for Container and Automounter Layouts

Displaying physical sample containers (such as Uni-Pucks, Spine pucks, and crystallization plates) and beamline automounters (such as ISARA, SAM, and CATS) across web interfaces requires a geometric layout representation that is responsive, auditable, and compatible with robotics. We decided to model container geometries using normalized parametric coordinates—Cartesian $(x, y) \in [0, 1]$ for rectangular envelopes and polar $(r, \theta)$ with $r \in [0, 1], \theta \in [-\pi, \pi]$ for circular envelopes—stored as structured JSON attributes in the database, rejecting static SVG asset files or fixed pixel coordinate templates. This design enables responsive client-side canvas rendering across screen sizes, enforces machine-readable spatial validation for automounter loading, and allows facility staff to define new container and automounter geometries via the administrative interface without deploying new front-end graphic assets.
