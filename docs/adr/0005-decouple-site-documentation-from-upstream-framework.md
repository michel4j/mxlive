# Decouple Site Documentation from Upstream Framework Docs

MxLIVE's Sphinx documentation in `docs/source` was originally written when `basic-live` was internal to the repository, containing `automodule` directives and guides for core LIMS data models, access control, and generic views. Following the extraction of `basic-live` into an independent framework, we decided to scope `mxlive` documentation strictly to macromolecular crystallography beamline operations, MX data types, container layout specs, and facility deployment instructions, delegating all core LIMS primitives, scheduling engines, and generic APIs to `basic-live`'s own documentation. This prevents dual-maintenance overhead, eliminates broken internal imports in doc builds, and clarifies the boundary between framework and deployment.
