# Automated PDB Harvest and Beamline Attribution via mmCIF Metadata

Tracking facility impact and scientific productivity requires cataloging structures deposited into the Protein Data Bank (PDB) resulting from data collected at Canadian Light Source MX beamlines. Rather than relying entirely on manual researcher self-reporting or coarse grant number queries, we decided to automate structural deposition discovery by querying wwPDB and CrossRef APIs, attributing depositions to specific beamlines (`CMCF-ID`, `CMCF-BM`) through programmatic parsing of the standardized mmCIF `diffrn_source.pdbx_synchrotron_beamline` attribute via facility-specific mapping rules. This approach guarantees objective, automated bibliometric tracking, attributes scientific publications directly to the beamline stations that produced the data, and provides verified historical impact records for institutional reviews.
