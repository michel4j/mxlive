# Hybrid Authentication with Institutional SSO (LDAP/CAS) and Extensible django-allauth

User authentication at the facility relies on enterprise directory and Single Sign-On services (supporting both centralized POSIX LDAP directories with group privilege synchronization and institutional Jasig CAS via `django-cas-ng`). We decided to combine institutional directory/SSO authentication with `django-allauth` to enable modern federated academic and enterprise identity providers (such as ORCID and Microsoft Entra ID) without replacing or disrupting the facility authentication infrastructure. This allows external academic researchers and remote collaborators to log in via standard federated identities while preserving local institutional SSO authority for on-premises beamline access and staff administration.
